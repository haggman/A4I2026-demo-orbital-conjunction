# Agents for Impact 2026—Kickoff demo: which of these warnings is real?

**Under construction.** This is the kickoff demo for Agents for Impact 2026: a sixth problem, built to the
same shape as the five challenges, with the solution actually finished.

You operate a small constellation. Roughly 32,000 tracked objects share its sky, the warnings never stop,
and nearly all of them are noise. **Which ones are real, and what do you do about them?**

> **Our satellites are made up. Everything they could hit is real.**
